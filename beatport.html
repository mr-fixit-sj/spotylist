Adding the Beatport Top 100s

The Beatport Top 100s are fetched automatically every Monday, with a catch-up run on Thursday for any list that was missed. Nothing needs to be done by hand.

This page is a manual fallback, for when Beatport blocks the automatic fetch: the button below sends a list from your own browser. Beatport keeps no history, so a week that is fetched neither way stays empty.

Once: install the button

Drag this button to your browser's bookmarks bar:

Send to SpotyList

When a list is missing, per list

  1. Open one of the lists on Beatport:
    • Trance (Main Floor) Top 100
    • Trance (Raw / Deep / Hypnotic) Top 100
    • Techno (Peak Time / Driving) Top 100
    • Techno (Raw / Deep / Hypnotic) Top 100
    • Melodic House & Techno Top 100
    • Mainstage Top 100
    • Deep House Top 100
  2. Click Send to SpotyList in your bookmarks bar. The list is copied and a new GitHub issue opens (you need to be signed in to GitHub).
  3. Paste (Ctrl/Cmd + V) into the issue text and click Submit new issue.

The list is stored for the current week, matched to Spotify and published; the issue is closed with a short summary. Sending a list again in the same week replaces it.
